# mita-auth

An easy-to-use, framework-agnostic authentication & anti-abuse protection SDK.

---

> [!TIP]
> **Official Organization Notice**
> 
> This is the **official GitHub organization** for the `mita-auth` project. We reserved this organization name to protect the project's identity, community trust, and security ecosystem against typosquatting or impersonation.

---

### 📦 Key Highlights

* **Framework-Agnostic**: Zero UI dependencies in core modules.
* **Lean & Auditable**: Built on top of mature, community-vetted cryptographic and networking libraries.
* **Edge-Ready**: Out-of-the-box support for Cloudflare Workers, Vercel Edge, and Node.js runtimes.
* **Modular Architecture**: Import only what you need to keep frontend bundles clean.
